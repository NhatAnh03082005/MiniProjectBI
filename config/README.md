# Configuration

- **Mục đích:** lưu ví dụ cấu hình an toàn để các thành viên thiết lập môi trường.
- **Loại file:** template cấu hình không chứa secret hoặc credential thật.
- **Phụ trách dự kiến:** trưởng nhóm phối hợp với các thành viên kỹ thuật.
- **Trạng thái:** chưa cấu hình môi trường chạy; chỉ có placeholder ở thư mục gốc.
