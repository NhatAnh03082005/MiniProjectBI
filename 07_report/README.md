# Report

- **Mục đích:** quản lý nội dung và tài nguyên của báo cáo cuối kỳ.
- **Loại file:** bản thảo từng phần, hình minh họa và tài liệu tham khảo.
- **Phụ trách dự kiến:** trưởng nhóm tổng hợp; mọi thành viên đóng góp.
- **Trạng thái:** đã có tài liệu và hình cho phần ánh xạ dữ liệu; chưa tổng hợp báo cáo cuối kỳ hoặc tạo PDF cuối cùng.
